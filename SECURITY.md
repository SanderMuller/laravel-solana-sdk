# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately to
`github@scode.nl` rather than opening a public issue.

We will acknowledge receipt within 72 hours and aim to ship a fix or
mitigation within 30 days for confirmed reports.

## Supported Versions

The latest minor on `main` receives security fixes. Older minors are
fixed on a best-effort basis.
